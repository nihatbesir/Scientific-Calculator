# 🧮 Scientific Calculator Web App

## 🇦🇿 Azərbaycan Dili

**Pro Scientific Calculator** — **HTML5**, **CSS3 (Bootstrap 5)** və **JavaScript (ES6+)** istifadə edilərək hazırlanmış müasir, responsiv və tam funksional elmi kalkulyator veb tətbiqidir.

Bu tətbiq əsas riyazi əməliyyatlarla yanaşı, alaqli elmi funksiyaları (triqonometriya, logarifm, faktorial və s.), klaviatura idarəetməsini və hesablama tarixçəsini dəstəkləyir.

### 🌟 Özəlliklər
- **Elmi Hesablamalar:**
  - Dərəcə rejimində işləyən triqonomatrik funksiyalar (`sin`, `cos`, `tan`).
  - Logarifmik funksiyalar (`log10`, təbii logarifm `ln`).
  - Faktorial (`n!`), Kvadrat Kök (`√`) və Qüvvət (`x^y`).
- **Müasir İnterfeys (UI/UX):**
  - Tünd rejim (Dark Mode) və xüsusi neon dizayn.
  - Mobil və masaüstü cihazlar üçün tam uyğunlaşdırılmış (responsive) interfeys.
- **Klaviatura Dəstəyi:** Fiziki klaviatura düymələri ilə tam idarəetmə (`0-9`, operatorlar, `Enter`, `Backspace`, `Esc`).
- **Hesablama Tarixçəsi:** Əvvəlki əməliyyatı ekranın yuxarı hissəsində nümayiş etdirir.

### 🛠️ Texnologiyalar
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **UI Framework:** Bootstrap 5.3

## 🇬🇧 English

**Pro Scientific Calculator** is a modern, responsive, and fully functional scientific calculator web application built with **HTML5**, **CSS3 (Bootstrap 5)**, and **JavaScript (ES6+)**.

It supports standard arithmetic operations, advanced scientific functions (trigonometry, logarithms, factorials, roots), keyboard navigation, and calculation history tracking.

### 🌟 Features
- **Scientific Calculations:**
  - Trigonometric functions (`sin`, `cos`, `tan`) calibrated for degrees.
  - Logarithmic functions (`log10`, natural log `ln`).
  - Factorial (`n!`), Square Root (`√`), and Exponents (`x^y`).
- **Interactive UI & UX:**
  - Sleek Dark Mode interface with custom neon accents.
  - Fully responsive layout optimized for desktop and mobile devices.
- **Keyboard Navigation:** Full support for physical keyboard inputs (`0-9`, operators, `Enter` for calculation, `Backspace` to delete, and `Esc` to clear).
- **Calculation History:** Displays the previous expression alongside the current input and result.

### 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **UI Framework:** Bootstrap 5.3
